Karena Gambar sebelumnya cuma punya grid dikelompokkan per bulan (lewat Paging3 + `GalleryItem.Header`), dan koleksi foto user sangat besar (~23rb file), didiskusikan dulu soal pendekatan performa sebelum eksekusi (lihat bagian "Keputusan Desain" di bawah).

**File yang diubah:**

**Catatan koordinasi:** `ImageGalleryScreen.kt` adalah wilayah kerja hz19 menurut perintah asli. Sebelum menyentuh, dikonfirmasi dulu ke user bahwa hz19 tidak sedang aktif di file ini pada saat pengerjaan.

**Commit:**

## Keputusan Desain yang Diambil

1. **Gambar mode Folder pakai data non-paging terpisah** (`getImages()`), sedangkan mode Terbaru tetap Paging3 murni tanpa diubah. Alasan: pengelompokan folder cuma butuh data ringan (nama file & path, bukan buka gambar), sehingga aman diambil sekaligus meski jumlah file besar; sementara mode Terbaru dibiarkan pakai sistem "muat sedikit-sedikit" yang sudah terbukti ringan untuk device RAM kecil.
2. **State toggle per-kategori disimpan sebagai `Map<String, VideoGalleryMode>`** di `HomeViewModel` (bukan state terpisah per kategori) - sesuai salah satu opsi yang disarankan hz11 di perintah asli.
3. **`FileListWithModeToggle.kt` punya salinan sendiri untuk `FileRow`/`formatSize`** (dinamai `FileRowPublic`/`formatSizePublic`) karena versi asli di `HomeScreen.kt` bersifat `private` (khusus file itu, tidak bisa dipinjam file lain di Kotlin).

## Pertanyaan/Blocker untuk hz11 (mohon konfirmasi)

1. **Fitur "Analisis"** (menu: Semua Partisi, File Besar, Berkas Terbaru, Folder Kosong, File Redundan, File Duplikat, Keranjang Sampah) ditemukan di `HomeScreen.kt` - saat ini cuma tampilan kosong tanpa fungsi. Tidak disebut di perintah Tugas 1/2. Apakah ini juga scope hz25, atau ditunda/dipegang pihak lain?
2. **Ikon aplikasi & nomor versi app** - belum jelas apakah ini scope hz25 atau dipegang khusus hz11 (mengingat proses signing/keystore disebut sensitif di catatan proyek). Mohon konfirmasi.
3. **Kategori "Favorit" di grid Beranda** - user minta dihapus dari Beranda (karena fungsinya sudah ada di menu Favorit pada drawer, jadi dobel). Belum dieksekusi - ditunda sampai saya menyentuh file terkait lagi (kemungkinan bareng Tugas 2). Mohon konfirmasi ini keputusan final sebelum saya eksekusi.
4. **Bug lama: label bulan hilang di mode Terbaru Gambar** - user melaporkan header pemisah bulan cuma muncul untuk bulan berjalan, bulan-bulan lain tidak muncul labelnya (foto tetap ada). Ini bug yang sudah ada sebelum sesi ini (bukan dari perubahan saya), dan menurut user pernah coba ditangani akun lain tapi belum tuntas. Belum saya perbaiki - ditunda sampai saya menyentuh file terkait lagi.
